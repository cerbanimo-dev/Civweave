# Commonweave v1.0.16

## Display Surface Engine

This release begins the shared geometry system for illustrated interfaces.

- Adds `public/app/shared/commonweave-display-surface.js`.
- Adds `public/app/shared/commonweave-display-surface.css`.
- Defines reusable safe regions for full and narrow chalkboards, easels, wall and portrait holograms, multi-board dashboards, circular projectors, and observatory arches.
- Gives every mounted surface a constrained scroll viewport, responsive density rules, and stronger default contrast.
- Preserves semantic HTML forms and feeds instead of flattening content into artwork.

## Large visual payload

The remaining v1.0.15 visual assets are distributed as separate path-preserving packs so individual transfers remain below repository and chat download limits. Extract each pack over the repository root before committing the completed release.
