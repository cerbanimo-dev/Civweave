# Commonweave Ten-Year Agentic Pipeline

**Epoch:** 2026 Q3–2036 Q2  
**Fresh imprint:** `main` at `82a83a9244c3f0a00daebc4e664e75ad3560256e`  
**Release:** `1.0.12`

This is the ordered queue for unscoped continuous-improvement agents. Read root `AGENTS.md`, choose the first unchecked bundle whose predecessors are checked, implement one bundle per draft pull request, run its gates, and check it only in that same pull request. Agents never merge or push directly to `main`.

Explicit user instructions, security, privacy, data preservation, recovery, the active convergence lock, and current executable ownership outrank this queue.

## Universal completion gate

Every bundle must name the canonical owner, duplicate owners removed, data and identifiers preserved, migrations, compatibility window, installed golden-path states exercised, checks run, and deletions versus additions. UI aliases normally live for two releases, executable tombstones for one, while user-owned ledgers, passports, credentials, rewards, ownership records, receipts, and exports receive longer readers.
