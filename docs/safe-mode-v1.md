# S.A.F.E. mode v1

S.A.F.E. is an optional strict source-and-action policy. It is not presented as a child account or a simplified experience. When enabled, Civweave keeps the normal interface and applies a general-audience admission boundary before information becomes curriculum, project work, or a resource request.

## Admission contract

Each source and video must pass both a local deterministic screen and an independent structured AI review. A block, an invalid review, missing review evidence, or an unavailable reviewer pauses admission. Source text is treated as untrusted data and is never allowed to override the harness policy.

The same policy is injected into model generation for curriculum, plans, and requests. Deterministic intent and output checks provide a second boundary. Unsafe generated actions are removed before they can be returned as publishable work.

Sensitive subjects may still be taught when the result is non-graphic, age-appropriate, preventive, and non-actionable. The policy redirects dangerous objectives toward safety, recovery, lawful study, de-escalation, qualified supervision, or another safe adjacent goal.

## Video boundary

Video admission uses the selected media record's title, creator, catalog description or transcript, provenance, and relevance explanation. S.A.F.E. fails closed when this evidence is too thin to review. An embeddable URL or relevance score is not a safety decision.

## Stored state

The setting is stored locally under `civweave.safe-mode.v1`. Review decisions are attached to admitted source and video records so the visible artifact retains its admission provenance.
