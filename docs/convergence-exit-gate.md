# Convergence exit gate

The convergence program is complete only when all of the following are true.

## Ownership

- one active entry per realm
- one family navigation owner
- one shared AI-settings owner
- one guide runtime with realm adapters
- one state writer per domain
- one service worker
- one generated package manifest
- one direct local server and one direct gateway server

## Forbidden mechanisms

- zero hidden compatibility controls
- zero synthetic click relays
- zero mutation-observer application routers
- zero runtime source rewrites
- zero package builders parsing JavaScript source for manifests
- zero direct cross-realm private-storage reads outside adapters

## Reduction

- at least 40 percent fewer active runtime files than the Wave 0 baseline
- at least two runtime lines deleted for every runtime line added across the program, excluding tests and migrations
- no executable source retained only for historical reference

## Installed behavior

The complete golden path must pass under:

- fresh install
- supported upgrade
- offline reload
- device restart
- missing optional model
- missing hosted gateway
- mobile keyboard open
- missing or corrupt cached asset recovery

The release is blocked by any data-loss migration, split ownership, hidden compatibility choreography, or route that works only through a historical entrypoint.
