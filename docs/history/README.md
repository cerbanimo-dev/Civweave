# Historical records

This folder holds point-in-time records that are useful for provenance but are not current source-of-truth entrypoints.

- [`releases/`](./releases/) contains versioned release notes.
- [`audits/`](./audits/) contains versioned interface, recovery, and contract audits.
- [`design/`](./design/) contains versioned backlogs and design snapshots.

Keep filenames intact when moving historical records so commit history and repository search remain easy to follow. New historical records should be written directly into the appropriate folder rather than landing at repository root first.
