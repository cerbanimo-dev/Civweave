# Record evidence for review

## Inputs
- All previous stage artifacts
- Current diff and branch history

## Procedure
1. Inspect only intended changes and stale references.
2. Confirm no production promotion and no unauthorized irreversible action.
3. Summarize tests, unresolved risks and human approval needed.

## Outputs
- review-evidence.md: change summary, risks, evidence and PR link

## Acceptance
- The PR is reviewable and retains reliable proof; no unsupported claims of deployment.
