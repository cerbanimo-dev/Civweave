# Bug-fix workspace

Purpose: reproduce a specific observed failure, trace the active route to the existing canonical owner, preserve a failing executable contract, implement a narrow fix, and demonstrate that the actual installed surface works.

This workflow inherits all root contracts. Do not add a repair shim, duplicate owner, new chat, new listener, or runtime self-patch to hide a broken canonical implementation. If no reliable reproduction is possible, record the manual reproduction evidence and the closest stable prevention contract.
