# Convergence deletion waves

## Wave 0: Lock and inventory

- Freeze parallel runtime growth.
- Generate the executable graph.
- Establish the application manifest.
- Keep Living School PR #178 as the only demolition lane.

## Wave 1: Living School clean room

- One startup path.
- One state engine.
- One renderer.
- One delegated action controller.
- One Moss identity.
- One settings route.
- Preserve v151 user data through migration only.
- Remove room state, hidden launchers, relays, observers, old loaders, and duplicate services.

## Wave 2: Stable entries and adapters

- Add stable `/app/entry/<realm>.html` routes.
- Add one realm adapter contract.
- Remove private realm-storage knowledge from the family shell.
- Generate dispatcher and navigation maps from `public/app/app-manifest.json`.

## Wave 3: Package authority

- Generate service-worker and installer package lists from the application manifest.
- Remove source parsing from package builds.
- Reduce the service worker to cache lifecycle, offline routing, package status, and recovery.

## Wave 4: Server normalization

- Replace source-patched gateway startup with direct source.
- Establish one local server and one gateway server.
- Remove retired versioned server entrypoints after route-contract verification.

## Wave 5: Realm clean rooms

Order:

1. Commonweave
2. Cerbanimo
3. FellowFare
4. Anarchadia

Each realm must cross the same ownership, migration, deletion, offline, and golden-path gates before the next realm becomes the active lane.

## Wave 6: Compatibility collapse

- Old route aliases: two supported releases maximum.
- Executable tombstones: one supported release maximum.
- Old schema writers: forbidden after migration.
- Old schema readers: migration modules only.
- Hidden DOM compatibility targets and synthetic interaction relays: forbidden immediately.

## Wave 7: Convergence release

Release only after fresh install, supported upgrade, offline reload, restart, mobile keyboard, missing model, missing gateway, cache recovery, and the complete cross-realm golden path pass.
