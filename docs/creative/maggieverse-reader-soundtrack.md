# Maggieverse soundtrack reader · playlist-building sheet

This editorial sheet is for curating **ten separate Spotify playlists**. Each title starts with a sequence number so it can be built manually in a stable order. The companion CSV contains **48 proposed tracks** and search links. These are proposals, not claims that the tracks are already in the user's Spotify library.

## How to use

1. Create each numbered playlist in Spotify, or keep the existing **Civweave Radio** and **FellowFare Radio** as ambient choices.
2. From the CSV, search the track and artist and add it in the listed order. Paste the actual Spotify track URL in the empty `spotify_track_url_to_fill` column.
3. Use `draft_book_progress` as a **rough editorial scene-location estimate**, not a real page number. When the final EPUB is ready, import it into the Maggieverse Reader and use the on-screen reader page number to place cue links.
4. The **approximate playlist clock** is a rough ordering/mix planning position, not a measured track start or an automatic trigger. Album edits, remasters, live tracks and regional versions will change actual runtimes.
5. For a scene, choose a Spotify **track link**; for the entire stretch between scenes choose a **playlist link**. In the reader these are suggestions and manual Spotify embeds; they do not fire on the page turn.
6. Save/export the reader's book-specific JSON cue sheet. Changing the page length creates a distinct page edition.

## Canon and rights notes

- Book V is **Landry III — Drawn by Darkness**. Book IV's Commons assault resolves with zero team injuries. The post-six music remains distinct from the first six books.
- **God Save The Queens** by Vienna Vienna is a *proposed film closing cue only*, not an added last line to the prose. Obtain synchronization/master rights clearance before film use.
- All copyrighted songs remain Spotify-hosted and are not downloaded, copied, rehosted, remixed, or synchronized by the reader.
- Spotify Developer Policy prohibits synchronizing Spotify sound recordings with visual media and restricts commercial streaming applications; therefore this first implementation keeps the Spotify embed separately user-initiated. True automatic book/audio sync belongs to a separately licensed rights-cleared audio engine.
- The companion reader is an EPUB/TXT/Markdown text-first prototype. Imported book bytes do not leave the device through its code. Editorial cue JSON is local and exportable.
- Suggested scene-progress positions have **not** been aligned against a current canonical manuscript; update after an exact master EPUB is selected.
