# Creator Suite — nine original fanfiction worlds
All Creator Suite installations include nine built-in, reader-safe world generation protocols. No extra lore-model download is required. A user can choose one world or mix any number as a crossover. The active document agent injects only the selected packets with every model request, preserving the canonical saved-edit pipeline and provenance.

**Worlds:** Panel geography, gutters, variant histories · Mobile castles, remembered promises, guarded paths · Living ships, delayed communication, route ballots · Daemons, service orders, cosmic appeals · Neighborly monsters, folklore variance, rumor · Digital lives, embodied transit, resource accounting · Quest ledger, item rewards, essential labor · Colossal ecology, mecha engineering, signals · Restored local communities, renewable industry.

These universes are original genre blends with broadly recognizable science-fiction/fantasy conventions. References are humorous commentary rather than reproductions of copyrighted franchises.

Spoilers are handled by leaving unpublished source lore out of the public package, not by claiming a model can safely remember and suppress secrets. An optional LoRA is a separately evaluated future enhancement.
