幻想世界として語られるソーシャル・オペレーティングシステム

生きたいと思える世界を、織ろう。

民織（シヴウィーヴ / Civweave）は、ひとつの願いを、学び、役に立つ仕事、公正な交換、市民参加へと続く道筋に変えます。ローカルファースト、コミュニティ運営型で、ネットワークが途切れても動き続けるよう設計されています。

名前について：「民織」は、民（人びと・共同体）と織（織る・つなぎ合わせる）を組み合わせた意味を示す日本語表記です。通常の熟語の読みを当てるのではなく、ブランドの音はシヴウィーヴとして残しています。

物語

自治郷は引き裂かれた。だから、誰かが扉をつくった。

民織の世界は、自治郷 / アナーケイディア / Anarchadiaから始まります。そこではかつて、日々の協力そのものに魔法が宿っていました。けれど反魔法のファシスト蜂起が、人々に互いを疑い、自らの力を手放し、「誰かが人生をもう一度意味あるものにしてくれる」と約束する暗黒の魔術皇帝を待つことを教えてしまいます。

切羽詰まった発明

物語の中で、民織は「実現のための魔法道具箱」として組み上げられます。ひとつの万能呪文ではなく、好奇心を力へ変える学校、その力を役に立つ仕事へ変える工房、必要な場所へ資源を運ぶ市場、そして次に何をするかを皆で決める市民の鋳造所です。

目的は、罰する力を強くして闇に勝つことではありません。見捨てることが得にならない世界をつくることです。学ぶ、貢献する、交換する、居場所を持つ、身の回りを自分たちで形づくる。そうした現実的な道が増えるほど、「何をしても良くならない」という呪いが根を張る余地は小さくなります。

このファンタジーが意味するもの

上の政治的な言葉は、民織の架空世界に属する物語表現です。平たく言えば、民織は社会的孤立と調整コストを減らすためのソフトウェアです。目標を構造化された計画に変え、近くの知識や資源を見つけ、仕事の証拠を残し、価値を交換し、透明なコミュニティ自治へ参加できるようにします。

悪役は、現実の特定人物や政党を指しているわけではありません。ここでいう「闇」とは、疎外感、学習性無力感、欠乏、壊れた信頼が混ざり合い、権威主義的な約束だけが秩序への唯一の道に見えてしまう状態のことです。

生学舎 / リビング・スクール / Living School

名前：「生」は生きること、「学」は学び、「舎」は学ぶための居場所を表します。生学舎は「生きた学びの家」という意味を込めた表記で、ブランドの音はリビング・スクールです。

目的から始まる学び。生学舎は目標を中心に学習経路を組み、説明と練習を交え、「参加したこと」ではなく「実際に示した能力」を記録します。

  • 個人向け学習経路とローカルファーストの学習ツール
  • 練習、プロジェクト、クイズ、証拠に基づく進捗
  • 技能を神織での実際の仕事の資格へつなげられる
計画する · 作る · 届ける

神織 / セルバニモ / Cerbanimo

名前：「神」は創造、精神、そしてkamiという音の連想を、「織」は人・技能・成果を一緒に織ることを表します。Cerbanimoの由来にある「Cami-borne / Kami-borne」の言葉遊びと、創造の織機というイメージを日本語側でも響かせています。読みはブランドとしてセルバニモです。

仕事の領域。アイデアをクエストへ変え、責任の明確なステップへ分け、協力者を招き、結果を検証し、調整作業に埋もれることなく報酬とクレジットを分かち合います。

  • クエスト、ワークボード、貢献の証明、検証
  • 控えめなプラットフォーム手数料による有償サービス取引
  • AIと人間の協力者が、ひとつの記録されたワークフローを共有できる
公正に交換する · 自由に贈る

共市 / フェローフェア / FellowFare

名前：「共」は共に・共有を、「市」は市場と人が集まる場所を表します。共市は「一緒につくる市場」という意味を込めた表記で、ブランドの音はフェローフェアです。

ニーズ、提供、商品、サービス、贈り物、地域での直接交換を扱う領域です。共市は、寛大さと現実的な商取引を敵同士ではなく隣人として扱います。

  • 届く範囲のネットワークからニーズと提供を探す
  • 許可される地域では複数の決済・交換方法に対応
  • 通信が不安定でも地域発見を役立つ状態に保つ
提案する · 熟議する · 監査する

自治郷 / アナーケイディア / Anarchadia

名前：「自治」は自分たちで治めること、「郷」は人が暮らし関係を結ぶ土地・共同体を表します。自治郷は「自分たちで治める故郷・共同体」という意味を込めた表記で、ブランドの音はアナーケイディアです。

より広い自治郷の市民的中枢。コミュニティは提案を起草し、証拠を集め、合意形成を行い、無作為抽出の陪審を使い、意思決定がどう行われたかを見える台帳として残せます。

  • パスポート、提案、審理、透明な台帳
  • 検証された市民レビューにはコミュニティ報酬を付与できる
  • 自動化は人間による自治に対して説明責任を持つ

価値の流れ

中にいる人を所有せず、灯りを守る。

民織は、コミュニティ・メンバーシップ、計算資源の資金、サービス取引、ノード運営を分けて設計しています。ひとつの支払い方式が、気づかないうちに権力構造へ変わらないようにするためです。

メンバーシップは処理能力を支える

現在のローンチ時の仕組みでは、決済処理後の月額メンバーシップのサービス価値を分配します。メンバーは有効期限のない計算クレジットを受け取り、リザーブはAI処理能力とコミュニティのレジリエンスを支えます。

50% システム + 計算資源リザーブ25% ホスト運営者25% 神織

トップアップは実際の計算資源を裏づける

計算クレジットのトップアップは、使われるまで裏づけが必要な負債として扱います。サービス価値の大部分は、約束した計算資源を支えるために残されます。

70% 生涯計算クレジットの裏づけ25% ホスト運営者5% 神織

サービスは働いた人とホストに報いる

神織のサービス取引には5%の仲介手数料があります。現在の設計では、その手数料を神織とホストノード・スチュワードが半分ずつ受け取り、決済事業者の手数料や法的に必要な税を差し引く前の残りを、働いた人が受け取ります。

95% 外部費用控除前の働き手の価値2.5% ホストノード・スチュワード2.5% 神織

無料参加は設計そのものに組み込まれている

コミュニティの席は、有料会員であることと同義ではありません。ひとつのノードは、無料参加者、有料参加者、ローカル計算資源、共有処理能力、オフライン参加を別々の層として持てます。有料活動によってコミュニティが持続可能に提供できる範囲を広げながら、「支払うこと」を市民である条件にはしません。

ここに示す経済配分はバージョン管理されたローンチ方針であり、今後変更される可能性があります。決済処理、税、各法域固有の商取引ルールは、ここに示す割合とは別に適用されます。

ホストノード・スチュワードへ

王座ではなく、炉辺を守る。

スチュワードは、民織が暮らせる場所を運営します。Cloudflareに支えられたハブ、ローカルマシン、あるいはオンラインとオフラインの両方でコミュニティのデータとサービスを保つハイブリッドノードです。

スチュワードが得られるもの

スチュワードは、自分のノードに関連するメンバーシップ価値、計算トップアップ、対象サービス手数料から定められた取り分を得られます。また、処理能力の公開、ノードID管理、支払い接続、アカウント復旧、バックアップ参加、周辺ネットワークの到達性維持のためのツールも利用できます。

炉辺を使える状態に保つノードを保守し、容量を監視し、安全な更新を適用し、復旧経路を残します。
台帳を守るアイデンティティ、仕事の証拠、残高、自治記録、署名付き受領書の整合性を保ちます。

お金をきれいに精算する支払い基盤を接続し、取消・返金に対応し、約束した計算資源の裏づけを維持します。

民織とは？

民織（シヴウィーヴ / Civweave）は、インストール可能なWebアプリとして構築された、オープンソースかつローカルファーストのコミュニティ・オペレーティングシステムです。AI支援による意図の整理、学習、プロジェクトと労働の調整、地域交換、メッセージング、地図、参加型自治を、相互運用できるひとつの仕組みにまとめます。コミュニティはホストノードを通じて接続しながら、意味のあるオフライン能力と地域の管理権を維持します。

製品は四つの専門領域と共有Commonsで構成されます。生学舎 / リビング・スクールが学び、神織 / セルバニモが仕事と協力、共市 / フェローフェアが交換、自治郷 / アナーケイディアが自治を担い、民織Commonsが意図、アイデンティティ、チャット、地図、領域間の移動をつなぎます。

設計目標は簡単です。「こうだったらいいのに」を、学べて、資金をつけられて、共有できて、皆で治められる行動の連なりへ変えやすくすること。
