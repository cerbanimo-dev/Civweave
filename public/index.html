INSTALLATION RULE

No browser-mode campus

Commonweave application routes redirect here until they are opened in installed display mode. On iPhone and iPad, installation is completed through Safari’s Share → Add to Home Screen command.

LOCAL-FIRST BACKEND

The device is the source of truth

Records are written locally before any transfer is attempted. Peer links and gateways consume a durable outbox; they never replace local state.

PORTABLE RECOVERY

Carry the package another way

A local host or mobile kit remains available for devices that cannot install directly from this browser.
