Cloudflare token settings and retry
  1. Token permission: Account → Workers Scripts → Edit.
  2. Account resources: include the Cloudflare account that owns this Guild.
  3. GitHub Actions: replace CLOUDFLARE_API_TOKEN, then rerun the Guild deployment workflow.
  4. Local setup: rerun the command shown below after updating the token.

node scripts/provision-cloudflare-account-edge-v1.mjs --host-id <host-id> --strict

Durable Objects are covered by Workers Scripts permission; Cloudflare does not present a separate Durable Objects permission row.

WHY THE ANCHOR MATTERS

The Cloudflare Guild host remains usable without a local Anchor. A local companion is strongly recommended because it can retain Guild identity and state for recovery, local-first services, and federation work even when the public edge is unavailable.
