# Civweave RC17.8 — Cerbanimo Spatial Parity Pass

Cerbanimo visual mode now adds a universal spatial search/command palette, live attention inbox, data-backed object lists, resumable local form drafts, richer project/mission/resource/community/activity close-ups, direct project selection, task inspection, and improved visual continuity.

## Major changes

- Search every Cerbanimo room, project, mission, resource, and party member with Ctrl/Cmd+K or the Search control.
- Attention Inbox surfaces pending submissions, invitations, urgent tasks, and unassigned work.
- Visual detail views now include live state-backed entity rows instead of metrics alone.
- Project rows open the selected project workbench.
- Mission rows open the selected task workflow.
- Resource, community, review, and activity rows remain inside spatial mode.
- Universal form workbench supports locally persisted drafts and Kamiya-assisted publication handoff.
- Escape closes spatial overlays; room/place restoration remains active.
- Offline cache version bumped so installed copies receive the update.

## Known boundary

The deepest task editor and some cryptographic Passport/model-provider operations still use the advanced console because those workflows already contain mature authority, validation, and key-handling logic that should not be duplicated.
