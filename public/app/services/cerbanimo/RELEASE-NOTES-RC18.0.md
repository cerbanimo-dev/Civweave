# Cerbanimo RC18.0 · Closed Circuit

Cerbanimo-only visual-native feature pass.

## Added
- Evidence and Review Chamber with task selection, evidence sealing, model review, queue and receipt access.
- Communications Bay with project, mission and direct-relay messages stored in local-first state.
- Spatial attention triage for reviews, urgent work and unassigned missions.
- Project editing for title, purpose, status and visibility.
- Mission creation and editing from the Project Workbench.
- Mission lifecycle progress display and direct transitions into proof review.
- Appeals archive view and review-console routing.
- Rewired visual hotspots so evidence and communications no longer depend on traditional pages.

## Compatibility
The traditional interface remains available only through the explicit recovery route `?classic=1`.
