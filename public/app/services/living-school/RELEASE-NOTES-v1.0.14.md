# Living School v1.0.14: fitted displays and standard navigation

- Calibration labels remain available to the hotspot data and accessibility tree but are never painted over the illustrated rooms.
- Learning paths, research, retrieval, misconceptions, opportunities, and constellation views now route to purpose-matched devices.
- Every interface device uses a defined screen rectangle or silhouette clip path and a valid responsive type scale.
- Conventional app-theme blocks are neutralized inside chalk and hologram surfaces so content reads as part of the object.
- Visual mode has a full-width top bar with Back, Home, Map, Campus, and direct model/API-key access.
- Merlin can be dragged and remembers his local position without changing platform state.
