# Commonweave 1.0.0 RC21.4 · Native Commit and Social World

- Approved Quad handoffs now open destination-specific editable preview forms.
- Commits create native Cerbanimo quests, Living School schools, FellowFare listings, and Anarchadia proposals.
- Every commit records deterministic duplicate protection, source context, before-and-after snapshots, and a reversible receipt.
- Import failures stop safely when a destination state schema is missing or incompatible.
- Rollback removes only the native record created by the handoff and preserves lifecycle history.
- Presence now supports private, party, community, and public visibility.
- Nearby collaborators appear as avatars with activity bubbles, join controls, and local invitation staging.
- The Quad lifecycle includes staged, approved, committed, and rolled-back action history.
