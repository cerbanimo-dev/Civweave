# Commonweave Cabinet Family v1.0.4

The installed application is software-first. It opens `/app/fullscreen-family-v104.html?system=commonweave` and displays the selected system’s existing application full-screen.

The physical cabinet renderer, cabinet images, calibration tools, and archived room imagery remain in the repository for marketing and visual production. They are deliberately absent from the service worker’s `DEVICE_REQUIRED` list and therefore are not downloaded as part of the user’s offline installation.

The family host owns:

- the visible `Cabinet Mode` label and release number;
- exactly four labeled system-traversal buttons, excluding the current system;
- status dots and notification counts derived from local canonical state;
- the universal AI settings dialog used by every system, including nested FellowFare settings;
- the live guide chat for Weaveling, Moss, Kamiya, Rook, and Merlin.

The underlying software surfaces remain responsible for their native workbenches, data, curriculum, quests, exchange ledger, governance, and local-first state.
