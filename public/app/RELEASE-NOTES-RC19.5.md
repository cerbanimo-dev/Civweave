# Cerbanimo RC19.5 — World Engine Migration

- Migrates all 25 Cerbanimo visual scenes to the Commonweave World Engine.
- Converts existing hotspots into declarative world objects while preserving every classic-screen handoff.
- Adds one deterministic resident and room-specific ambient activity to each operational district.
- Persists world-object and resident interaction state locally.
- Preserves the previous visual renderer as an automatic compatibility fallback.
- Keeps deep links, browser history, spatial search, object drawers, forms, proof custody, communications, and visual-native operations intact.
