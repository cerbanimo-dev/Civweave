# Civweave RC21.5 · Intention Steward

Civweave can now maintain a durable, cross-system model of an intention instead of losing the thread after a handoff.

## Added

- Persistent monitored intentions with goals, success conditions, constraints, ordered steps, dependencies, source records, health, progress, blockers, and version history.
- Automatic reconciliation against live Cerbanimo, Living School, FellowFare, and Anarchadia records.
- Meaningful-change detection for completion, blockers, review requirements, inactivity, and plan drift.
- Quad conversation notices when a monitored intention materially changes.
- Natural-language plan controls for status questions, blockers, pause, resume, abandon, add/remove/replace steps, deadlines, and strategy changes such as faster, cheaper, safer, or simpler.
- Review-required high-level adjustment proposals. Civweave never silently rewrites the plan.
- An intention adjustment review panel with approve and reject controls.
- Automatic import of existing Civweave journeys into the monitoring ledger.
- Twenty-second local monitoring loop plus immediate refresh on application storage and handoff lifecycle changes.

## Safety and ownership

Plan adjustments alter Civweave's orchestration plan only after user approval. Destination records remain owned by their native applications and continue to use the existing handoff review and native commit process.
