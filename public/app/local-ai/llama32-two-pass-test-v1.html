Llama 3.2 3B · Two-pass JSON trial

Experiment only; does not modify normal Moss/Weaveling generation. Pass 1 freely drafts a short learning plan with Llama 3.2 3B Instruct. Pass 2 reuses the same loaded model with Hugging Face's token-level StructuredOutputProcessor to compile strict JSON. The schema masks invalid next tokens; independent parsing checks the completed result.

Model: Llama 3.2 3B Instruct · ONNX q4f16 · WebGPU · ~2.4 GB downloaded weights. Install it once in Civweave Settings → AI Downloads. This experiment never selects E4B or automatically downloads model weights. The compiler companion is self-hosted after the app loads it.
