# RC22.2.4 — visual defaults for testing

- Routes Civweave service launchers into the visual-first entry points for Living School, Cerbanimo, Anarchadia, and FellowFare.
- Forces Living School to reopen in visual campus mode when launched from Civweave or with `?visual=1`, even if an older classic preference had been stored locally.
- Bumps Civweave and Living School service-worker cache versions so installed test builds receive the updated visual-default shell.
