# Civweave RC19.1 — Cerbanimo Living World + Living School Visual Continuity

RC19.1 merges the RC19.0 Cerbanimo living-world polish line with the RC17.11 Living School visual-campus continuity line.

## Preserved from RC19.0
- Latest Cerbanimo living-world interface, spatial behavior, release lineage, and offline bundle.
- Existing Anarchadia, FellowFare, shared runtime, install, relay, and launch-forge components.

## Added from Living School RC17.11
- Thirteen illustrated Living School locations and five functional gateway destinations.
- Image-aligned hotspots, room action tray, directory, room history, swipe and keyboard navigation.
- Fit/fill image modes for tall mobile displays.
- Precise handoffs into classic Living School workspaces with return-to-room continuity.
- Offline caching for all visual-campus assets.

## Merge policy
RC19.0 is the package baseline. Only the Living School visual-mode additions were layered over its matching Living School implementation, avoiding replacement of the newer Cerbanimo code.
