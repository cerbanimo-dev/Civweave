# RC21.0 — Living World Foundation

Civweave now has a reusable living-world layer rather than a collection of inert destination placeholders.

## Added

- Shared scene registry and persistent scene visits.
- Scheduled residents with local conversation memory.
- Unified search across scenes, residents, events, journeys, discoveries, and compatible local data.
- Cross-system journey templates with persistent progress.
- Ambient daypart and live-event state.
- Persistent discoverables and a local event ledger.
- User presence state and public engine APIs for future multiplayer adapters.
- Living district placeholders that expose resident, event, and discovery infrastructure before final art arrives.
- Offline caching for the new living-world runtime.

## Compatibility

The original Civweave interface and all four applications remain available through Classic tools. Existing Town Square building hotspots and the Quad AI handoff remain intact.
