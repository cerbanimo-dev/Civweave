GUILD HOSTING · CHOOSE YOUR ROOT

Create a Guild from a phone or an always-on machine.

A Guild belongs to its Guildkeeper and members. Creating one here never makes the Guild you downloaded Civweave from pay for your hosting.

Premier route · phone or tablet

Mobile Guild

This device becomes the founding Pocket Node and stores the Guild's signed identity and mesh state locally. No Cloudflare Worker is created. No cloud account is required, and the current download site is not inherited as your backend.

Mesh code loads only when you create the Guild.

Later, this same Guild can attach a desktop/Raspberry Pi host or its own Cloudflare public edge without changing Guild identity.

Persistent route · desktop / Pi / server

Desktop or Raspberry Pi Guild

Run Civweave on hardware that can stay awake. Docker uses that machine's CPU, storage, and network. If you add a Cloudflare public edge, its Worker and Durable Objects are created in the Cloudflare account you authenticate for that Guild, never in the Guild you downloaded from.

Desktop / Pi Guild directions

A persistent host and a Pocket Node can both back up the same Guild. They are complementary replicas, not competing Guilds.

NEXT · NAME THE QUEST

Bring an intention. It does not need to be polished.

Inside Civweave, Weaveling helps turn what you want to make possible into an editable Quest: a path through whatever learning, work, resources, and agreements the intention actually requires.

PARTY · WHEN THE ROAD IS SHARED

Travel solo, or gather Heroes around the same Quest.

Solo work remains fully valid. When different strengths belong together, Civweave helps Heroes find one another and form a Party without forcing every Quest into a committee meeting with snacks.

GUILD · A LOCAL HEARTH

Find a Guild that can keep your local world connected.

Guilds are Civweave community hosts. Their Guildkeepers keep infrastructure dependable and welcome Heroes into a community that can share capacity, find collaborators, and keep working when the wider network gets unreliable.

RECOVERY · ANOTHER ROAD HOME

Carry Civweave another way when you need to.

The ordinary doorway is only one route. Portable install and seed files can move the essentials between devices or communities when the network is inconvenient, unavailable, or simply being dramatic.
