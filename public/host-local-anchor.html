CIVWEAVE HOST STEWARD

Add a local Anchor

Your Cloudflare host remains the public doorway. A local Anchor keeps signed recovery checkpoints, its own continuity key, and a persistent local companion so the hub can be reconstructed even after a wider grid failure. It is strongly recommended, never required.

1. Identify the Cloudflare hub

No verified local Anchor detected yet.

2. Install the local companion

Install Git and Docker Desktop/Engine with Docker Compose v2 on the laptop, desktop, Raspberry Pi, NAS, or home server that will hold the backup.

git clone https://github.com/cerbanimo-dev/Civweave.git
cd Civweave
cp .env.federated.example .env.federated
docker version

The full local Civweave companion remains useful even when the cloud is healthy. Its persistent volume keeps federation/node state locally.

3. Issue a one-time pairing grant

On a trusted steward shell, use the Cloudflare fabric operator token to issue a short-lived grant. Do not paste the operator token into this web page.

curl -sS -X POST "https://civweave-node-cloud.glaedn.workers.dev/api/fabric/nodes/<NODE_ID>/anchors/pairing" -H "Authorization: Bearer $NODE_FABRIC_OPERATOR_TOKEN" -H "Content-Type: application/json" --data '{"recipientId":"passport:YOUR_ID","displayName":"Local Anchor"}'

Copy only the returned pairing.token into the local machine. The Cloudflare operator secret stays off the Anchor.

4. Start the companion + cryptographic Anchor

Add these values to .env.federated:

CIVWEAVE_CLOUD_NODE_ORIGIN=https://my-hub.nodes.commonweave.earth
CIVWEAVE_ANCHOR_PAIRING_GRANT=PASTE_ONE_TIME_GRANT_HERE
CIVWEAVE_ANCHOR_SYNC_HOURS=6
docker compose --profile anchor --env-file .env.federated -f docker-compose.federated.yml up -d --build

The Anchor profile is optional. It creates an independent persistent Anchor volume and automatically restarts with Docker. The local private key never leaves this machine.

5. Verify recovery health

curl http://127.0.0.1:8787/api/federation/health
curl https://my-hub.nodes.commonweave.earth/api/node/anchor/status

A healthy Anchor has proved that it downloaded, signature-verified, wrote, read back, and retained the latest signed recovery checkpoint. Civweave classifies hubs as cloud-only, locally-anchored, or redundantly-anchored.

Weekly Button stipend

Healthy independent Anchors receive a small infrastructure stipend: 3 / 2 / 1 Buttons per week for the first, second, and third independent Anchor. The automatic maximum is 6 Buttons per hub per week. Stale proofs, stale checkpoints, low recovery coverage, or duplicate signing keys do not qualify.

Backup stipends are separate from AI-compute compensation. During incomplete disaster recovery, local work can continue provisionally, but irreversible external settlement stays frozen until signed ledger history is reconciled.

Return to host setup

The steward reminder is persistent but non-blocking. It dismisses only after the cloud node reports at least one healthy cryptographic Anchor; “Remind me tomorrow” remains available from Civweave.
