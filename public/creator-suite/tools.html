WordCraft · local document tools

Inspect DOCX files, extract text or export a PDF with a separately installed WordCraft CLI. The source file stays on your computer. This connector is not hosted by Civweave and is unavailable until you launch the companion process and authorize it.

Setup instructions for Windows, macOS and Linux

Start the loopback bridge on the same computer to enable this panel. No data is uploaded to Civweave servers.
