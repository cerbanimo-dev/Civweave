Install local document tools

Optional, private, on-device processing using upstream Craft command-line tools.

1. Install the tool you need

These are independent open-source applications. Civweave does not download or execute any installer on your behalf.

  • WordCraft official releases — install the wordcraft-cli executable for document inspection, text extraction, and PDF export.
  • CADCraft official releases — install the cadcraft-cli executable for DXF/DWG inspection and SVG export.
  • Node.js official installation — version 22 or newer on the computer running the bridge.

Validate downloads using checksums from the upstream release. CLI binaries must be discoverable on the computer's PATH or configured using WORDCRAFT_CLI and CADCRAFT_CLI.

2. Launch the optional Civweave companion

From a checked-out copy of Civweave containing tools/creator-craft-bridge/server.mjs, launch one of the commands below. The process listens only on your own computer.

Windows PowerShell

$env:CIVWEAVE_CRAFT_ALLOWED_ORIGINS = 'https://civweave-staging.pages.dev'
node tools/creator-craft-bridge/server.mjs

Linux or macOS

CIVWEAVE_CRAFT_ALLOWED_ORIGINS=https://civweave-staging.pages.dev node tools/creator-craft-bridge/server.mjs

Use the actual trusted Civweave URL in CIVWEAVE_CRAFT_ALLOWED_ORIGINS if different. The localhost development origins are also allowed by default. Do not enter an unfamiliar website origin.

The companion prints a random token on launch. Keep the terminal open and paste that token into the connection box on the tool catalog page. Select a file from your device and choose an available action. The original is not overwritten.

3. AI access remains approval-gated

Only tools backed by an installed CLI and a user-selected file are registered in the Creator Suite's local tool registry. Each AI-triggered operation asks for approval. The local adapter cannot read other files based on a model-generated pathname, and it cannot send or publish documents to a guild.

The tools page is functional only on the same desktop computer as the running companion. Opening Civweave on your Android phone will not connect to a desktop's 127.0.0.1. Phone-to-PC execution requires a separately authenticated HTTPS host-node integration; do not open the bridge's local port to the internet or your LAN.

Current limitations

This is an experimental native command-line connection, not a full browser editor port. Files are capped at 8 MiB, PDF/SVG exports at 12 MiB, and two jobs may run at once. Real WordCraft/CADCraft binary compatibility and document fidelity still require end-to-end verification. Conversion does not guarantee lossless round trips.
